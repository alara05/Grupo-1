🧪 Ejercicio: Foreign Key e Integridad Referencial

🎯 Objetivo

Aprender qué es una clave foránea, la integridad referencial y la diferencia entre ON DELETE CASCADE y NO ACTION.

🧱 Creación de Tablas

CREATE DATABASE BibliotecaFK; USE BibliotecaFK; CREATE TABLE ARTICULO ( id_articulo INT AUTO_INCREMENT PRIMARY KEY, nombre VARCHAR(100) NOT NULL ); CREATE TABLE PRESTAMO ( id_prestamo INT AUTO_INCREMENT PRIMARY KEY, fecha DATE NOT NULL ); CREATE TABLE DETALLE_PRESTAMO ( id_detalle INT AUTO_INCREMENT PRIMARY KEY, id_prestamo INT, id_articulo INT, cantidad INT, FOREIGN KEY (id_prestamo) REFERENCES PRESTAMO(id_prestamo) ON DELETE CASCADE, FOREIGN KEY (id_articulo) REFERENCES ARTICULO(id_articulo) ON DELETE NO ACTION );

🧠 Conceptos Clave

Integridad Referencial: No puedes usar datos que no existen.
CASCADE: Si eliminas un préstamo, se eliminan sus detalles automáticamente.
NO ACTION: No puedes eliminar un artículo si está en uso.

🧪 Inserción de Datos

INSERT INTO ARTICULO (nombre) VALUES ('Libro A'), ('Libro B'); INSERT INTO PRESTAMO (fecha) VALUES ('2026-04-20'); INSERT INTO DETALLE_PRESTAMO VALUES (NULL,1,1,2);

🔍 Pruebas

❌ Prueba 1: Error de integridad

INSERT INTO DETALLE_PRESTAMO VALUES (NULL,99,1,1);
Debe fallar porque el préstamo no existe.

✅ Prueba 2: CASCADE

DELETE FROM PRESTAMO WHERE id_prestamo=1;
Los detalles se eliminan automáticamente.

❌ Prueba 3: NO ACTION

DELETE FROM ARTICULO WHERE id_articulo=1;
Debe fallar porque el artículo está en uso.

🎓 Preguntas

  • ¿Qué pasa si eliminas un préstamo?
  • ¿Por qué no puedes eliminar un artículo?
  • ¿Qué garantiza la integridad referencial?
