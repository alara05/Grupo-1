IN

IN

Concepto: Permite verificar si un valor pertenece a una lista o subconsulta.
Sintaxis:
columna IN (valor1, valor2)
Enunciado: Mostrar los productos que han sido vendidos.
SQL:
SELECT NOM_PRO FROM PRODUCTOS WHERE COD_PRO IN ( SELECT COD_PRO_V FROM DETALLE_VENTA );
BETWEEN

BETWEEN

Concepto: Filtra valores dentro de un rango.
Sintaxis:
columna BETWEEN valor1 AND valor2
Enunciado: Mostrar facturas entre enero y junio 2026.
SQL:
SELECT * FROM FACTURA WHERE FEC_FAC BETWEEN TO_DATE('01/01/2026','DD/MM/YYYY') AND TO_DATE('30/06/2026','DD/MM/YYYY');
LIKE

LIKE

Concepto: Permite buscar patrones en texto.
Sintaxis:
columna LIKE 'patrón'
Enunciado: Mostrar clientes cuyo nombre empieza con J.
SQL:
SELECT NOM_CLI FROM CLIENTES WHERE NOM_CLI LIKE 'J%';
ANY

ANY

Concepto: Compara con al menos un valor de la subconsulta.
Sintaxis:
columna > ANY (subconsulta)
Enunciado: Mostrar productos con precio mayor a alguno menor a 1.
SQL:
SELECT NOM_PRO FROM PRODUCTOS WHERE PRE_UNI > ANY ( SELECT PRE_UNI FROM PRODUCTOS WHERE PRE_UNI < 1 );
>

Mayor que

Concepto: Filtra valores mayores a otro.
Enunciado: Mostrar productos con precio mayor a 1.
SQL:
SELECT * FROM PRODUCTOS WHERE PRE_UNI > 1;
<

Menor que

Concepto: Filtra valores menores a otro.
Enunciado: Mostrar productos con stock menor a 200.
SQL:
SELECT * FROM PRODUCTOS WHERE STOCK < 200;
=

Igual

Concepto: Compara igualdad exacta.
Enunciado: Mostrar empleados con la factura de mayor total.
SQL:
SELECT NOM_EMP, APE_EMP FROM EMPLEADOS WHERE CED_EMP IN ( SELECT EMP_PER FROM FACTURA WHERE TOTAL = ( SELECT MAX(TOTAL) FROM FACTURA ) );
